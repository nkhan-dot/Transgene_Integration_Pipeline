
# PURPOSE
Aim to analyse and process long read nanopore sequencing data from Transgenic A.gambiae mosquito strains to identify the location of the transgene in the host native genome. 

## LOGIC OF THE PIPELINE
Sequencing reads from ONT sequencing runs are aligned to the Ifakara reference genome. Thus, specfic reads touching the artifical transgene introduced into the ifakara reference genome can be isolated and visualsied in IGV. This allows for visual conformation of the transgene presence in the Trasgeneic mosquito genome.
